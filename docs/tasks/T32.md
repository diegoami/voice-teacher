## Scope

Package and deploy the same accepted app/server to the chosen target after explicit provisioning/deployment authorization. Transfer private runtime state safely, establish one writer, configure persistent storage, HTTPS, secrets and backups, and preserve the option to roll back to the local server.

## Done when

1. Authorized deployment serves an authenticated phone session over stable HTTPS with no credentials in images, source code or logs.
2. A documented handoff pauses the old writer, transfers pending/exported progress and resumes on the new server without concurrent writers or lost/duplicate events.
3. Restart, backup restore, upgrade and rollback smoke checks pass on the selected host; actual latency and operating-cost observations are compared with the decision assumptions.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
Manual: execute the chosen-target smoke, handoff, backup/restore and rollback runbooks; rerun relevant automated deployment checks.
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

This task is optional after the local release and gated by the actual hosting decision. Deployment authorization is distinct from creating this backlog.
