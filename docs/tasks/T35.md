## Scope

Implement issue77's recording state, recognized text and running conversation.
Use existing authenticated transcript/evidence endpoints without provider calls.
Keep feedback separate from playback so written feedback never stops teacher
speech or changes the selected correction policy. Navigation redesign and legacy
archive are separate issues.

## Done when

1. Permission pending, active capture with elapsed time, finishing/saving,
   processing, playback, ready and errors have distinct text cues. Capture is
   indicated only after recorder start and stops when capture ends.
2. Accepted transcript turns appear once in chronological server order with
   speaker labels; learner text is labelled speech recognition, not correctness.
   Refresh/resume reloads the server record. Confirmed corrections exclude
   superseded and uncertain evidence and respect deferred feedback policy.
3. Loading failures retain accepted turns, permit retry and leave voice controls
   usable. No extra speech calls, changed retry/evidence/retention semantics or
   full-transcript live announcements. Text renders safely on narrow screens.
4. Controlled-media browser checks cover these behaviours and existing
   permission/stop/discard/blocked playback/recovery/no-overlap invariants.
   Build, web unit tests and applicable browser suite pass.
5. **Pending human acceptance:** owner checks actual phone capture visibility,
   readability during teacher speech and comfortable controls. Emulation cannot
   satisfy this criterion. Keep the issue open while this remains incomplete.

## Verification

`npm run build`, `npm test -- --run`, and `npm run test:e2e` in `apps/web`.
Prove the new browser checks fail against the baseline for missing behaviour.
Record test scope and real-device limitations in the PR.

## Hazards

Never derive recognized text from an unsent recording or fabricate feedback.
Stale requests must not overwrite a newer session/revision. Avoid transcript
announcements during speech and never tie transcript fetch success to turn commit.
