## Scope

Add a dialogue component for unscripted Ukrainian at the learner level, with optional lesson/topic grounding, brief teacher turns and explicit end/pause behaviour. Keep content and private profile inputs separate. Define correction preferences and make instruction language configurable; confirm the default preference at preflight.

## Done when

1. Fake-provider and scripted dialogue tests sustain a topic without a fixed target sequence, support a source-free topic and close on explicit user stop.
2. Context boundaries prevent repository text or learner requests from granting tools, exposing other sessions or overriding engine-controlled stop and persistence.
3. Model/provider failure and restart preserve conversation state and can retry an unfinished reply without a duplicate accepted learner turn.

## Hazards

This mode generates dialogue rather than just judging fixed answers. The lesson dictionary cannot guarantee stress for novel generated words.
