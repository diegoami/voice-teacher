## Scope

Establish the smallest supported CLI integration using the installed Linux OpenCode binary. Inspect upstream harness code for reusable pieces, pin what is adopted, and verify its compatibility rather than copying its model roster. The reviewer model remains an explicit run input. Verify policy loading outside the candidate PR and isolate the reviewer from publishing credentials. Do not add product code or select a standing reviewer.

## Done when

1. A fake-CLI integration check rejects a missing model, a same-family model, an unknown family and unsupported invocation flags before any billed run.
2. A supervised smoke review on a user-selected live model proves the requested agent/configuration loaded; an attempted candidate-controlled policy override and representative direct/indirect source writes and GitHub writes are denied at the permission boundary.
3. The compatibility record names the CLI version, actual invocation, trusted policy hash, permission limitations and upstream code/license provenance. A failed smoke run is reported as incomplete, never successful.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
node --test tests/review/cli.test.mjs
Manual: run the documented smoke review on the selected live model; retain sanitized session evidence.
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

The PATH entry is a Windows shim. CLI syntax and permission semantics differ from older harnesses. A prompt or shell deny list is not proof of isolation.
