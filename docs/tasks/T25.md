## Scope

Apply an explicitly reviewed migration manifest into the configured private progress destination. Begin with a small sample, reconcile it, then import the chosen remaining scope. Record import provenance and stable IDs; preserve all original files. Actual private-data writes require the verified destination and operator-selected manifest.

## Done when

1. Synthetic import is transactional/idempotent and a mid-import failure or retry cannot duplicate history or partially activate projections.
2. A real selected sample has reconciled counts and provenance with unresolved entries preserved in the private report; the chosen remaining scope is either reconciled or explicitly left incomplete.
3. Source hashes remain unchanged, unrelated review history is untouched, and recovery/export of the imported records matches the approved manifest.
