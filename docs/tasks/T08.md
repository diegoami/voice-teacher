## Scope

Register configured local checkouts and allowed subdirectories, expose separate course catalogues and activate only validated revisions. Pin each session to its source commit/content hash and private compiled snapshot. Handle uncommitted content only through explicit snapshot semantics.

## Done when

1. Two sources containing lesson 4B can be selected independently and preserve distinct item/evidence identities.
2. An invalid refresh leaves the last valid catalogue active; a running/resumed session uses its original snapshot after the checkout changes.
3. Paths escaping the configured root are rejected and repository scripts are never executed; dirty content is labelled and hashed rather than presented as committed.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text

```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

A repository can contain multiple independent tracks. Do not infer one global course position from the selected repository.
