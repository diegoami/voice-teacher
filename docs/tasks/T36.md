## Scope

Expose original inputs already retained by approved T25 imports. Show the
legacy-session records separately from aggregate tracker and queue references.
No new import, source scanning at request time or canonical practice events.
Use opaque archive IDs; every read is scoped to the paired owner. Original
text stays plain text, and source-labelled transcripts are distinguished from
notes/summary records without generating replacement conversation turns.

## Done when

1. An authenticated learner can list and read their retained legacy inputs in
   History, with original labels, source date where available, source hashes,
   retained record counts/statuses and links to selected supporting groups.
   Unresolved context remains explicitly unresolved. References stay distinct
   from actual session records and current app sessions.
2. No source filesystem path is accepted by an endpoint. Missing IDs, absent
   configuration and unavailable/corrupt archives fail safely. Another learner
   cannot enumerate/read the owner's records. HTML in source text renders as
   text. Original source files, evidence and manual lesson choices are unchanged.
3. Synthetic API/projection/browser checks cover owner isolation, missing data,
   labels, plain text and retry. Existing migration tests and web checks pass.
   Real retained material is checked locally without putting private text,
   manifests or paths in this repository, PR or review packet.
4. Document exactly the existing readable scope and outstanding scope. The
   accepted initial batch has three original inputs (one transcript-labelled
   session record, one tracker and one queue), 335 records, nine selected groups,
   75 supporting records and 260 unresolved records. Broader sessions remain
   unavailable until separately reviewed imports; do not mark them migrated.
5. **Pending human acceptance:** owner confirms expected records on the phone.
   Any additional import requires its exact reviewed manifest/reconciliation;
   no additional import is authorized by this implementation.

## Verification

Run relevant `tests/migration` and API checks using synthetic records; build,
web unit tests and legacy browser checks. First reproduce the missing archive
behaviour against baseline. Keep this PR open pending human acceptance and the
existing merge gate; do not close issue78 solely from synthetic checks.

## Hazards

Never expose entire cross-learner batches or filesystem lookup through an API.
Retained context is readable history, not newly accepted practice or settled
mapping. Do not copy real learner material into automated fixtures or reviewers.
