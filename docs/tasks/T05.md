## Scope

Add configurable persistent storage for learners, session snapshots, activities, turns, observations, evidence and outbox jobs. Implement migrations and explicit session revision ownership. Keep speech/model calls outside transactions and server data outside code/content checkouts.

## Done when

1. A committed session/event survives process restart with the same IDs and ordering; rebuilding a projection preserves all underlying evidence.
2. Injected transaction failure leaves neither a partial state update nor an orphan evidence/outbox row, and repeated insertion cannot duplicate an event ID.
3. Migration checks cover a new database, a supported older schema and safe refusal of an unsupported newer schema without modifying it.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
uv run pytest tests/storage -q
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

Do not commit the database binary. An in-memory log or end-of-session save does not satisfy durability.
