## Scope

Create the product package and repeatable local developer commands. Port the tested phase/correction behaviour behind interfaces for judging, speech and persistence. Preserve the POC as reference and avoid importing it by manipulating sys.path. Introduce language profiles without changing the measured Ukrainian defaults.

## Done when

1. The existing representative lesson sequence, staged help, later-step handling, stop and two-sitting behaviour run through the product package with fake providers.
2. The product package has no implicit sibling checkout or fixtures directory requirement and makes no network calls in offline tests.
3. Documented install/test commands work from a fresh checkout; the POC suite remains runnable and unchanged behaviour is accounted for.
