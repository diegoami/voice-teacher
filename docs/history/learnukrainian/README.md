# History from learnukrainian

On 2026-10-29 the practice repository
[diegoami/learnukrainian](https://github.com/diegoami/learnukrainian) was
separated from this product: it keeps the Ukrainian curriculum, the learner's
records and its ChatGPT Voice lessons, and no longer holds product material.
These files moved here unchanged from learnukrainian commit `e21a952`.
Relative links inside them point to paths in that repository at that commit.

| File | What it is |
| --- | --- |
| [product-analysis/](product-analysis/) | The 2026-09-23 analysis "From a manual loop to a product" (formerly `docs/product/`). [`../../architecture.md`](../../architecture.md) is the living copy of its file 03. |

| [VOICE_ITERATIONS-claude-line.md](VOICE_ITERATIONS-claude-line.md) | The adherence log as it stood on 2026-09-27: checklist C1–C16, the Claude versions v1–v4 with their test results, g1, and every test run, including the lesson-connector (POC 0) runs. |
