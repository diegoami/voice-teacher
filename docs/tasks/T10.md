## Scope

Port configurable recognition and synthesis into durable turn stages, with language locking, explicit timeouts, stress rendering and reproducible cache keys. Keep local cache/audio storage separate from progress export. Use fake providers for automated integration and explicitly chosen credentials for a limited live smoke check.

## Done when

1. Empty/failed recognition leaves the lesson unadvanced; a suspected recognition problem is stored separately from a confirmed learner correction.
2. Synthesis failure after a saved judgement recovers without another evidence transition; cache identity includes model, voice/settings, pronunciation version and output format.
3. Known authored stress remains intact, plain learner-facing text contains no stress notation, and a documented live recognition/synthesis smoke check records sanitized timing and actual provider configuration.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
uv run pytest tests/providers tests/integration/test_voice_pipeline.py -q
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

The current adapter exposes no confidence score. Do not create confidence-based behaviour from a field the provider does not supply.
