## Scope

Add an isolated app-managed progress checkout and asynchronous pull/export/commit/push worker. Expose locally saved, exported and remotely pushed states. Limit the initial topology to one active writer server and retain pending jobs after every failure.

## Done when

1. Temporary local Git remotes exercise disconnected practice, failed push, restart and successful retry without losing or duplicating events.
2. A dirty or conflicting checkout cannot commit unrelated files, overwrite differing events or force-push; distinct batches reconcile without dropping history.
3. Destination changes and server handoff require an explicit verified procedure; source content remains unchanged and the app reports last successful remote sync.

## Hazards

Do not put Git operations on the critical teaching path or treat a local commit as a remotely backed-up event.
