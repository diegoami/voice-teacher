## Scope

Export committed outbox work as immutable per-session batches under the app-owned namespace of a configurable private repository. Include enough private snapshot and state-event information to reconstruct interrupted sessions and progress. Generate readable views from events, keeping one canonical event history.

## Done when

1. Export, import and replay of complete and interrupted synthetic sessions reproduce their state, assistance labels, corrections and cross-source provenance.
2. Repeated export/import is idempotent; an event ID with different contents is rejected, and partial writes cannot masquerade as complete batches.
3. Writes remain inside the configured app namespace; content repositories, unrelated card-review events, database binaries, secrets and raw audio are excluded.

## Hazards

Git exports can contain sensitive text and snapshots. Never infer that the configured remote is private without operator verification.
