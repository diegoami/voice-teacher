## Scope

Run the first daily-use beta on the actual phone with external lessons and private progress. Complete short repetition and guided activities, pause across sittings, interrupt connectivity and restart the server. Report observations and anonymized measurements without committing raw learner recordings or transcripts.

## Done when

1. Human evidence records both modes on Android, working mic/playback, task audibility, replay/stop and continuation after refresh/server restart.
2. A temporary Git outage preserves local practice and subsequently pushes exactly the accepted event batches to the private destination.
3. Record actual end-of-recording to first-audible-response median/p95, sample count, cache state and device/network context; release-blocking failures become reproduced task issues.
