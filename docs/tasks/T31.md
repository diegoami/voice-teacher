## Scope

Compare an always-on home machine and suitable persistent VM/container hosting against measured daily use, phone-to-provider latency, backup requirements, operating cost and data location. Determine whether single-instance SQLite remains appropriate. This is a decision task, not permission to buy infrastructure or create accounts.

## Done when

1. The comparison cites current primary sources for changing prices/features and identifies assumptions, measured demand, persistent-storage and restore requirements.
2. A proposed topology explains TLS, authentication, secrets, process restart, backups and the single-writer Git sync/handoff boundary.
3. The owner-selected target and cost constraints, or the explicit decision to remain local, are recorded before a deployment task is dispatched.
