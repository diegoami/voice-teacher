## Scope

Add bounded retries, timeouts, upload/duration limits and configurable per-session usage budgets. Report actual metered versus estimated/unknown costs, and measure client recording-end to first audible response alongside server stages and cache status. Keep personal text out of routine metrics.

## Done when

1. Fake-provider failure and rate-limit tests prove bounded work, useful recoverable errors and cancellation without duplicate evidence or unbounded billing loops.
2. Unknown provider usage remains unknown rather than zero; estimates are labelled and a session budget stops additional work at a stable recoverable boundary.
3. Telemetry separates upload, recognition, judging, synthesis and playback, includes sample counts/cache state, and excludes credentials and learner text.

## Verification

required manual participation at main-session preflight before dispatch.

## Hazards

A server response time is not end-to-end voice latency. Historic hard-coded prices must not be presented as current measured billing.
