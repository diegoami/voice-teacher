## Scope

Add tap-to-talk with optional hold-to-talk, teacher text/task cards, recording/processing/playback states, replay and stop. Submit stable request IDs and recover a lost response by checking the existing turn. Keep teacher playback and recording coordinated.

## Done when

1. Browser tests with controlled media drive a full repetition and guided turn, double tap, request retry and interrupted playback without duplicate submissions or overlapping recording/playback.
2. Denied microphone permission, empty/short recording, unsupported media type and blocked playback provide an actionable recovery while retaining session state.
3. Task instructions are accessible in text, stop works during pending work, and refresh can recover the last accepted response without replaying the learner attempt.
