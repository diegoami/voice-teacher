Produce a private dry-run reconciliation report with source counts, imported/ambiguous entries and conflicts. Preserve source distinctions and never invent assistance labels absent from the evidence.

## Done when

1. Synthetic tracker/queue/session fixtures yield a complete count reconciliation with preserved original source, later repetitions and corrections; ambiguous rows remain unresolved rather than guessed.
2. Dry run performs no writes to source checkouts, database or progress repository and produces a reviewable private report.
3. Repeated planning yields the same proposed IDs/mapping and identifies records that lack sufficient evidence without dropping their original information.
