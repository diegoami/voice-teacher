# T02 Run and publish reviews against the exact PR head

- **Kind:** infrastructure
- **Milestone:** Review workflow
- **Issue:** [#2](https://github.com/diegoami/voice-teacher/issues/2)
- **Branch:** `task/T02-<short-description>`
- **Merge after:** [T01](T01.md)
- **Implementer:** main session by default; a native subagent from the main
  session's model family may implement. Record the actual identity/family on
  the PR. The implementer produces the GitHub PR.
- **Reviewer:** independent different-family OpenCode model selected ad hoc for
  this PR and invoked through the CLI; record provider/model, variant, family,
  session ID and reviewed SHA. See [process](../process.md).
- **Evidence:** [production plan](../production-plan.md) and the referenced
  predecessor contracts; reuse measured POC behaviour where relevant.
- **Owns:** tools/review/runner and publisher; tests/review; review brief template; docs/process.md.

## Scope

Wrap the verified CLI adapter with a fresh pinned review checkout, full task brief, bounded process lifecycle and durable review artifacts. Separate model execution from the trusted GitHub publisher. Adopt upstream runner/parser components only after checking their compatibility. Provide a dry-run/local-artifact mode; keep ad hoc model choice mandatory.

## Done when

1. Integration tests prove checkout base/head match the PR, stale-head publication cannot approve, stdin closes, deadlines stop only the owned process tree, and failures retain diagnostic artifacts.
2. Missing criteria, not-run criteria without required corroboration, truncated output, contradictory verdicts and nonzero exits cannot produce approval. Publish the complete review with its model/session/head and limitations.
3. A supervised real PR review is recorded using the explicitly selected different-family model. Rework on a new commit invalidates the earlier approval; no automatic merge or silent model substitution occurs.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
node --test tests/review/runner.test.mjs tests/review/publication.test.mjs
Manual: review a small concrete PR and inspect the published SHA and complete report.
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

Self-approval through a GitHub owner account may be unavailable; report comments as comments. Never let PR-supplied configuration control the reviewer.
