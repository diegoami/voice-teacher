## Scope

Add versioned source/course/lesson, session creation/status, turn, pause/resume/finish and audio endpoints with typed client responses. Pair a personal client to a learner and keep administrative configuration protected. Serve same-origin assets initially; keep hidden targets, provider keys and internal filesystem paths server-side.

## Done when

1. Unauthenticated, wrong-learner and stale-session requests cannot read or change sessions, transcripts or audio; administrative source/progress changes require the configured operator identity.
2. A fake-provider API session creates, accepts/retries a turn, pauses, resumes and finishes with documented status/error shapes and no hidden targets in pre-attempt responses.
3. Pairing/session-cookie or token handling, request-origin protections appropriate to that scheme, upload limits and sanitized provider errors have positive and negative tests.

## Hazards

Secret URL access is insufficient. Configuration changes must not silently change the learner or active progress destination.
