## Scope

Extend local sources to server-managed clones of explicitly configured remotes, branches/tags and subdirectories. Fetch and validate updates before activation and retain old snapshots for session continuation. Credentials stay server-side and source operations remain read-only to the remote.

## Done when

1. Temporary remote tests clone two catalogues, fetch a new valid revision and preserve sessions pinned to the earlier lesson.
2. Unavailable remote, malformed manifest and unsupported schema leave the existing catalogue usable; no repository hook/script or remote write is executed.
3. Administrative configuration rejects disallowed paths/remotes according to the documented operator policy, and credentials/internal paths never appear in client output.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text

```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

Bring-your-own material does not mean executing source-controlled code or exposing an arbitrary unauthenticated clone endpoint.
