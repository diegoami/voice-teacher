## Scope

Create the mobile-first TypeScript client and installable app shell, served from the API origin. Pair to a configurable server and select source, course, lesson/topic and supported mode. Remember choices while preserving explicit learner identity. Finalize the UI library at preflight; React is the plan default.

## Done when

1. A browser pairs with the fake local server, selects either of two source catalogues and starts the chosen lesson/mode without hard-coded lesson paths.
2. Unsupported modes explain availability, catalogue/server failures are recoverable, and changing the source leaves an existing session resumable on its pinned revision.
3. Production build, responsive keyboard/touch selection checks and manifest/installability checks pass; provider secrets are absent from built client assets.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text

npm --prefix apps/web test -- --run
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

Server selection and progress destination are different settings. Do not expose Git credentials or arbitrary server filesystem browsing.
