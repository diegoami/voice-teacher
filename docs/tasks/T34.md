## Hazards

`agy --sandbox` concerns terminal restrictions and is not proof that file-write
 tools cannot edit a workspace. Default workspace writes are auto-allowed. Never
point the trial at the live product worktree or copy the user's whole profile.
A successful JSON envelope alone does not attest which underlying model ran.
