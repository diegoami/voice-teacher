# Reading list with deliberate errors — POC 1, run 2

The same Session 4 sentences, but eighteen of them contain one mistake a
learner could make: a Russian word, a wrong case ending, a wrong verb form
or a wrong gender. Eight are correct, as controls. Read **exactly what is
written**, mistakes included: the question is which recogniser writes down
what you said and which one quietly corrects it. A teacher can only correct
what the recogniser keeps.

The mistake in each line is noted in the source of this file (`said →
correct`), not on the page, so you are not tempted to fix it while reading.

## How to record

Same as the first reading (see `reading_list.md`): the lesson phone, its
built-in recorder, default `.m4a`, about 30 cm away, lesson pace, two
seconds between sentences, no numbers read, no restarts. Say the mistakes
naturally, as if you believed them. Name the file `errors-1.m4a`.
