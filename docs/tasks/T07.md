## Scope

Adapt the existing learnukrainian package shape to the versioned curriculum contract without editing source files. Extract deterministic data and maintain a stable identity mapping. Missing derived targets require an explicit preparation step and validation; do not generate a different lesson implicitly at session start. Move embedded personal context into private session inputs.

## Done when

1. Synthetic existing-format packages produce the expected opening, target sets, guided tasks, recall prompts and mode capabilities while preserving stress marks.
2. Malformed counts, missing targets and unknown source mappings fail before a session starts with actionable errors.
3. Read-only access is sufficient; source hashes remain unchanged and private learner fields never appear in the reusable catalogue output.

## Hazards

The old package mixes authored material and personal context. Regression fixtures must not introduce real transcripts or private profiles.
