## Scope

Select a short phrase set from the lesson or private weak-item queue and run listen-and-repeat independently of the full guided routine. Add optional recall-before-model behaviour using the same durable evidence contract. Respect explicit mode capabilities and configurable language profiles.

## Done when

1. A repetition-only lesson runs, retries/replays, stops and resumes without requiring guided steps or targets unrelated to the selected set.
2. Heard-and-repeated material is labelled repeated; independent recall is recorded only for an accepted uncued attempt made before the answer was supplied.
3. Reviewing a queued item preserves its original and current practice sources and does not reset another course position.

## Hazards

A similarity match is evidence of repetition rather than a pronunciation or mastery score.
