## Scope

Expose free conversation with topic and correction preference controls, pause/resume and history. Add a small original regression set for bounded dialogue, supported corrections, task adherence and hidden-target handling across the three modes. Keep paid model evaluations opt-in with explicit model inputs.

## Done when

1. Browser tests select all three modes, sustain a free dialogue with fake providers, change feedback preference and resume without losing mode or topic.
2. Offline eval fixtures catch an invented correction, wrong turn reference, premature target disclosure and incorrect evidence label; the evaluation report separates modes.
3. A bounded user-selected live free-conversation check documents dialogue quality and remaining generated-speech stress issues; missing human/live checks remain explicitly incomplete.

## Verification

Planned checks, not commands claimed to exist or pass today. Resolve paths and
required manual participation at main-session preflight before dispatch.

```text
uv run pytest tests/evals -q
npm --prefix apps/web run test:e2e -- free-conversation
Manual: short live conversation using the selected model and correction preference.
```

The PR records one result per numbered criterion, relevant baseline/regression
checks and any manual evidence. Independent exact-head review precedes merge.

## Hazards

Do not use repetition metrics as free-conversation quality measures. Existing provider/model benchmarks are small historical samples.
